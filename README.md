# Time and Space Complexity Analysis

This module focuses on understanding the efficiency of algorithms. It covers how to measure the performance of Java code as the input size ($n$) increases.

---

## 🚀 Projects Included

- ✅ **Linear_Complexity.java**: Implementation of $O(n)$ complexity using a single loop.
- ✅ **Quadratic_Complexity.java**: Implementation of $O(n^2)$ complexity using nested loops.
- ✅ **Separate_Loops_Complexity.java**: Demonstration of $O(n)$ complexity with multiple separate loops.
- 📝 **NOTES.md**: Comprehensive documentation on asymptotic notations and growth rates.

---

## 🛠 Concepts Covered

- **Asymptotic Notations**: Understanding Big-O ($O$), Omega ($\Omega$), and Theta ($\Theta$).
- **Growth Rates**: Analyzing how different algorithms scale ($O(1)$ to $O(n^2)$).
- **Optimization Strategy**: Learning how to write code that minimizes memory and execution time.
- **Constant Dropping**: Understanding why $O(2n)$ simplifies to $O(n)$.
